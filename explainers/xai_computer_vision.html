About this demo — ResNet-18 is a supervised CNN classifier trained on ImageNet 1K. Scores are softmax probabilities over all 1000 classes. The image is resized and center-cropped to 224×224 pixels, exactly what the model sees.

Grad-CAM backpropagates the top-class gradient to the last convolutional stage (7×7 feature map) to highlight which spatial regions drove the predicted class.

SHAP (GradientExplainer) estimates how much each pixel contributed to the top prediction, compared to a black baseline image. It averages gradients at 20 random points between the baseline and the input, so the map changes slightly each run.

Integrated Gradients (Sundararajan et al., 2017) accumulates the gradients of the top-class score along a straight path from a black baseline image to the input, and multiplies them by the difference between input and baseline. It satisfies the completeness axiom: the attributions add up to the difference in model output between input and baseline — shown below the image when you select the Integrated Gradients view.
